Lab guidelines

Use university resources safely and responsibly.

Before your session

  1. Submit a booking and wait for store approval.
  2. Carry your university ID and booking receipt.
  3. Read operating instructions and complete required training.
  4. Use equipment only for the approved academic or club activity.

After your session

  1. Switch off and clean equipment as instructed.
  2. Return all items to the store in-charge.
  3. Report damage or missing accessories immediately.
Late returns are subject to a fixed ₹250 fine for both students and faculty. The store in-charge verifies payment and clears the fine in the portal.
This portal uses a shared server database for users connected to the same running server. Student/faculty demo sign-in uses an entered identity; use university authentication before real deployment.
